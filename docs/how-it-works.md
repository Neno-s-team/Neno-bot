# 她是怎么想的

两大块：**世界引擎**决定她此刻在哪、在干嘛、遇到了什么；**多层大脑**决定她看没看到你的消息、怎么想、怎么说。
两块都跑在同一个后端进程里（FastAPI + SQLite，`data/bot.db`），通道只负责收发。

```
你 ──消息──▶ 通道（终端 / Telegram）──▶ 后端
                                        ├─ 多层大脑 app/services/mind/
                                        └─ 世界引擎 app/services/world/
你 ◀──到点才发── 通道 ◀── 投递表（几点发哪一句）
```

## 一条消息的一生（`app/services/mind/`）

1. **感知**（`perception.py`）：消息到了不等于她看到了。按她此刻的"打断等级"抽一个看手机的时刻——
   刷手机时几乎马上，写论文时过一阵，上课只瞥一眼通知，睡着了看不到。等级来自世界（`world_link.py`）。
2. **第一反应 L1**（`appraisal.py`）：小模型快速判断这是什么话、心里咯噔了没有、急不急。
3. **深思 L2 + 自我 L3**（`deliberation.py`）：拿着工作记忆（最近的事、记得的事、在意的事、此刻的处境）想清楚：
   他什么意思、我什么感受、说哪几点、哪些不说、分几条。之后有一道一致性检查（`consistency.py`）。
4. **表达 E1–E3**（`expression.py`）：把"要说的意思"写成她的口气，拆成几条，去掉不像聊天的东西。
5. **投递**（`delivery.py`）：给每一条排好发送时间（打字要时间、两条之间有间隔、犹豫会停一下），写进投递表。
   通道到点取走发出去，回执之后这句话才进聊天记录。
6. **夜里**（`reflection.py`）：她睡着后回想这一天，留下值得记的、修正对你的看法、放下或生出在意的事、想好明天的打算。
   记忆会淡（`memory/`），关系会慢慢变（`relationship.py`）。

**主动找你**（`proactive.py`）走的是同一条路，只是起点不是你的消息，而是她自己的念头：今天遇到的想说的事、
惦记的事、睡前想好的、好久没聊、发了你没回。念头自己冒出来，时机合适、她想清楚了才发。

## 她的世界（`app/services/world/`）

- **引擎**（`engine.py`）：实体（人、地方、东西）+ 事件 + 定时任务，按真实时间推进。所有随机都从种子派生，可以回放。
- **她的一天**（`life.py`，节律在 `content/world/rhythms/life.json`）：睡觉、吃饭、上课、赶任务、空档里挑事做。
  需求（饿、困、闷）会推着她做选择；你们聊天里她说过的打算也会影响她挑什么。
- **城市**（`city.py`）：真实的杭州地图，去哪儿要花时间和钱。
- **会发生的事**：日历和节假日、真实天气、校园和城里的活动（`happenings.py`）、
  现实里正在上映的电影和展览（`real.py`）、路上的小事（`moments.py`）、东西会坏、钱会花、任务有期限。
- **身边的人**（`npcs.py`）：导师、室友、家人会找她，由便宜模型扮演，每天有调用上限。
- **上网**（`surf.py`、`browser.py`）：她刷手机时真的在看网页；有感觉的留一两句，之后可能跟你提起。

## 通道（`channels/`、`telegram_gateway/`）

通道只做三件事：把你的话交给后端（`POST /chat`）、取到点该发的（`GET /mind/deliveries/due`）、
发出去后回执（`POST /mind/deliveries/{id}/ack`）。所以接一个新平台只要写这三步，参考 `channels/telegram_bot.py`。

## 想动手改

- 跑测试：`python -m pytest -q`（不联网、不调模型）。
- 配置都在 `.env`，默认值在 `app/config.py`。
- 世界的内容（节律、小事、活动、人物）都是 `content/world/` 下的 JSON，改完重启生效。

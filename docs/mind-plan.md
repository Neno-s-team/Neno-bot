# Neno 多层大脑规划

日期：2026-10-16。状态：规划，尚未实现。不修改现有聊天主链、Gateway、env 或人设开关。

关联文档：[`world-simulation-plan.md`](world-simulation-plan.md)（世界模拟规划）、[`world-engine-plan.md`](world-engine-plan.md)、[`world-cognition.md`](world-cognition.md)。

## 0. 定位

- 目标是拟真人：思考过程参照人脑的分层与时间尺度，而不是一次调用里“演”出所有规则。
- **只有一个大脑。** 聊天消息、世界事件、需求越阈都进入同一个认知周期；世界中的 Neno 决策也由本方案的 L2 承担，不另设一套“世界脑”。
- **只有 Neno 使用多层大脑。** NPC 一律由廉价 LLM 单次调用驱动（见世界规划第 6 节）。
- **与人设无关。** 人设只通过“自我卡”进入（气质、价值观、自传式记忆、文风），更换人设不改框架。

## 1. 总体结构

```text
触发 → L0 感知/注意 → L1 直觉 → L2 深思 + L3 自我 → 表达 E1–E3 → 提交
              ↑                                            ↓
         待想队列 ←────────────── 记忆系统 ←───────── L4 反思（睡眠/空闲）
```

每次触发是一个认知周期（cycle），每层输出单独持久化。

## 2. 触发源

| 触发 | 例子 | 起始层 |
| --- | --- | --- |
| 消息到达 | 用户发来消息 | L0 |
| 状态变化 | 下课、洗完澡 | 检查待想队列 → L2 |
| 需求越阈 | 饿、累、想他 | L2 |
| 入睡 / 空闲时重要性累积过阈 | 晚上躺下 | L4 |

## 3. 各层

### L0 感知与注意（代码，不调用模型）

- **能否感知**：手机位置（身上/包里/充电）、静音、是否睡眠。数据来自世界状态。
- **可打断等级**（由当前活动决定）：

| 等级 | 含义 | 例子 |
| --- | --- | --- |
| 0 | 不可打断 | 睡觉、考试、洗澡 |
| 1 | 可瞥一眼 | 上课 |
| 2 | 可短回 | 走路、排队 |
| 3 | 可聊 | 空闲 |
| 4 | 专注聊天中 | 正在和用户聊 |

- **看手机时刻**：`P = 1 − e^(−λ·Δt)`。λ 由打断等级决定，未读条数、来电、联系人优先级会提高 λ。看手机时刻用带 seed 的抽样预先计算，不轮询、不调用模型。
- **输出**：`seen = none | preview | opened` 及时间。预览只截取前 N 字。预览中出现紧急信号时直接交给 L1，允许抢占当前活动。

### L1 直觉（廉价模型，JSON Schema 约束输出）

- 输入：预览或全文、当前状态、精简自我卡、在意事项标题。
- 预览阶段跑一次；点开全文后用全文修正一次。

```json
{
  "category": "分享|提问|求安慰|约行动|调情|冲突|确认|晚回复",
  "gut": "他跟谁吃饭？",
  "affect_delta": {"valence": -0.2, "arousal": 0.3},
  "urgency": 0.1,
  "cues": ["小雨", "吃饭"],
  "depth": "fast|normal|deep",
  "reply_will": "now|later|not"
}
```

- **允许误判**，L2 可以推翻。
- fast 路径：`depth = fast` 且打断等级 ≥ 2 时跳过 L2，直接进入表达层。

### L2 深思 + L3 自我（主模型，开思考，一次调用分两段输出）

输入：工作记忆包（第 5 节）+ L1 输出 + 世界当前可执行动作候选 + 时间差。

**L2 输出**：

- `interpretation`：对用户意图的揣测
- `feeling`：想清楚后的感受
- `decision`：是否回复、是否发起世界行动，或两者都做
- `intents`：世界意图，交给世界引擎检查和结算；意图不是已完成行动
- `state_delta`、`memory_notes`、`belief_updates`（每条带可信度）

**L3 输出**（如何表现自己）：

```json
{
  "say_points": ["问一句是谁", "表现得不在意"],
  "hidden": ["其实有点吃醋"],
  "leak": 0.3,
  "tone": "随便",
  "length": "short",
  "n_messages": 2,
  "hesitate": true,
  "sticker": null
}
```

**一致性检查由代码完成**：时间线、行动主导权、与世界事实的冲突。不通过则打回 L2 一次；第二次仍不通过，退回保守回复。

### 表达层

| 层 | 职责 | 可见输入 |
| --- | --- | --- |
| E1 规划 | 直接由 L3 输出构成，不单独调用 | — |
| E2 措辞（主模型，不开思考） | 写成真人口语 | **只看** L3 规划、`gut` 与 `leak`、文风卡、最近几条原话；**看不到 L2 推理** |
| E3 渲染（代码） | 格式禁令检查、拆条、表情包校验、TG 动作 | — |

- **泄露机制**：E2 按 `leak` 强度把 `gut` 的情绪漏进说出口的话。
- **E3 的 TG 动作**：
  - 按 L0 的 `seen` 决定何时调用 `viewMessages` 标为已读。
  - 按字数与状态计算打字时长，期间 `sendChatAction` 显示“正在输入”。
  - `hesitate` 为真时，显示输入后停止，稍后再发。

## 4. 状态模型

只保留真正影响选择的量：

| 状态 | 说明 |
| --- | --- |
| `valence` / `arousal` | 情绪好坏与激动程度，按半衰期衰减（初始约数小时，可调） |
| `inhibition` | 抑制力 = 气质基线 − 疲劳 − 深夜 − 激动程度；决定 `leak` 上限 |
| `energy` / `social_energy` | 从世界同步 |
| `concerns` | 在意事项：强度、引用事件 ID、衰减率；被线索触发时重新升温 |
| 需求 | 与世界共享，不另存一份 |

## 5. 记忆系统

| 层 | 存储 | 生命周期 |
| --- | --- | --- |
| 感觉缓冲 | 现有消息聚合窗口 | 几秒 |
| **工作记忆** | 每轮现场拼装的上下文包 | 仅当前一轮 |
| 情景记忆 | `episode`：时间、地点、参与者、**她视角的**经过、情绪、重要性、引用的世界事件/消息/图片 ID、强度 | 会淡化 |
| 语义记忆 | `belief`：认识、可信度、证据 episode | L4 中更新 |
| 自我模型 | 人设种子 + 自传式记忆 | 仅在 L4 中极缓慢变化 |

**工作记忆包按固定槽位拼装**（token 上限可调，不按时间截断）：

- 当前情境（来自 L0）
- 2–3 件在意事项
- 检索出的最相关 ≤ 5 段经历
- 相关认识
- 最近几轮原话
- 自我卡

**检索打分** = 相关性 + 新近程度 + 重要性 + 情绪强度 + 记忆强度。线索来自 L1 的 `cues`。先用 SQLite FTS5 + 标签实现，不引入向量库。

**重要性由规则打分，不调用模型**：与用户有关、第一次发生、涉及承诺、情绪强烈加分。

**遗忘**：强度随时间衰减，每被回忆一次增强一次；低于阈值只保留大意。原始事实永远保留在世界账本与聊天记录中——**世界不忘，她会忘**。

**翻聊天记录**是一个世界动作，消耗世界时间，作用是让模糊的记忆重新清晰。

## 6. L4 反思

触发：入睡；空闲时重要性累积过阈。

1. 把当天经历提炼成大意，降低细节权重。
2. 从经历中提取或修正认识。
3. 处理在意事项：解决则关闭，否则衰减或升级。
4. 情绪收敛，作为第二天初始状态。
5. 生成第二天的意图与主动联系意图（主动联系独立开关，默认关闭）。
6. 自我模型微调，每次变化幅度有上限。

## 7. 待想队列与延迟回复

- L0 判定无空时只跑 L1；是否先短回由 `reply_will` 决定；消息进入待想队列。
- 打断等级升至 ≥ 2 时出队跑 L2，**按出队时刻的时间与状态重新评估**。
- **架构改动**：`/chat` 由同步一问一答改为立即返回 `accepted`；回复以带发送时间的投递计划写入 outbox，由 Gateway 按时投递。复用现有 outbox 持久化。

## 8. 数据表（SQLite，`mind_` 前缀）

| 表 | 内容 |
| --- | --- |
| `mind_state` | 当前状态 |
| `mind_cycle` | 每个周期：触发源、各层输出、模型、token、执行状态 |
| `mind_perception` | 感知记录 |
| `mind_deferred` | 待想队列 |
| `mind_episode` / `mind_belief` / `mind_concern` / `mind_intent` | 经历 / 认识 / 在意事项 / 意图 |
| `mind_self` | 自我模型 |

**幂等与回放**：`cycle_id` 由触发源 ID 派生；每层完成即落库，崩溃后从最后完成的层继续；回放使用已存输出，不重新调用模型。状态写入走世界统一提交入口并做版本检查。

## 9. 模型分配与降级

| 层 | 模型 | 计费用途 |
| --- | --- | --- |
| L1 | 廉价模型，JSON 输出 | `mind_l1` |
| L2 + L3 | 主模型，开思考 | `mind_think` |
| E2 | 主模型，不开思考 | `mind_expr` |
| L4 | 主模型，每天一次 | `mind_reflect` |

每条消息平均 2–3 次调用：fast 为 L1 + E2，normal 为 L1 + L2/L3 + E2。计费沿用 `app/services/usage.py` 按用途记账。

**降级**：

- L2 失败 → L1 + E2
- E2 失败 → 重试一次
- 整个周期失败 → 退回现有单次调用
- 世界不可用 → L0 默认打断等级 3 并标记

## 10. 代码位置

```text
app/services/mind/
  cycle.py          # 周期调度、按层断点续跑
  perception.py     # L0
  appraisal.py      # L1
  deliberation.py   # L2 + L3 + 一致性检查
  expression.py     # E2 + E3
  reflection.py     # L4
  state.py          # 情绪、抑制力、在意事项
  memory/           # store / retrieval / consolidation / wm_builder
  deferred.py       # 待想队列
```

`telegram_gateway` 需支持：带发送时间的投递计划、按时机标记已读、“正在输入”状态。

## 11. 验收情境

1. **上课时收到消息**：只看预览、保持未读；下课后回复，内容已按下课时刻更新。
2. **第一反应被推翻**：L1 吃醋，L2 想起是同组同学，说出口的是“哦” + “就你俩啊”。
3. **深夜泄露**：同一句话，15:00 与 01:00 的 `leak` 不同，回复不同。
4. **情绪余波**：未解决的在意事项经 L4 后，第二天被相关线索重新勾起。
5. **遗忘**：问三周前的小事，记得模糊，可能去翻聊天记录。
6. **前因不同，结论不同**：删掉一段相关经历，对同一句话的理解随之改变。
7. **崩溃恢复**：周期中途崩溃，重启后从断点继续，不重复发送。
8. **思考与表达隔离**：E2 输出从不出现 L2 推理原文。

## 12. 实施阶段

| 阶段 | 内容 | 依赖 |
| --- | --- | --- |
| P1 骨架 | 认知周期 + 状态 + L1 + E2 + E3 文本检查，保持同步返回 | 无 |
| P2 深思与记忆 | L2/L3 + 工作记忆拼装 + episode/belief 存储（FTS） | P1 |
| P3 感知与延迟 | L0（先用简易课表替代世界）+ 待想队列 + TG 已读与输入状态 | P2；需改 Gateway |
| P4 反思 | L4 + 遗忘 + 在意事项生命周期 | P2 |
| P5 接入世界 | 世界决策统一走 L2；主动联系意图 | 世界引擎解冻 |

P1–P4 不依赖世界引擎。

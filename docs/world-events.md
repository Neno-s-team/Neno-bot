## E1 真实天气（`app/services/world/weather.py`）
- Open-Meteo（免费、无密钥）取家所在坐标的实况 + 今明预报，`runtime.weather_loop` 每 20 分钟一次，联网在事务外。
- 落到 `street` 状态：weather（规则用）/ weather_label / temp / feels / wind / forecast；类别或说法变了才记 `weather.changed`。
- 有新鲜真实天气时扰动池的随机天气让路；断网超过 3 小时退回随机天气。测试、快进模拟不联网。
- 选项 `outdoor: 系数` × `weather.mood()`：雨、冷（体感 <10 递减）、热、大风不想在外面；不冷不热的晴天想出去。
- 开关：`WORLD_REAL_WEATHER`（默认开；只在 MIND_WORLD_ID 的世界上跑）。

## E2 世界事件（`app/services/world/happenings.py`，内容池 `content/world/events/common/*.json` + `content/world/events/<城市>/*.json`）
和扰动的区别：扰动是落在某个人身上的意外；这里是世界自己在发生的事，不管她知不知道、去不去。
- 池子 31 类：校园（讲座、读书会、开题/答辩、图书馆闭馆、食堂上新、晚会、银杏/樱花、期末周）、
  城里（银杏/红叶/梅花/樱花/荷花/桂花季、特展、电影、新书分享、商场活动、灯会、跨年、圣诞集市、马拉松）、
  身边（停水停电、楼上装修、新店开张、常去的店关门、地铁故障）、网上（双十一/双十二/618）。
- 每天 04:30 排一次：定下 8 天后那天的事（提前"公布"），突发的（地铁故障）当天定。建世界时回补 60 天内还在进行的。
- **她怎么知道**：群通知 / 刷手机 / 路过，按概率——没公布的无从知道，有的事她就是没看到。开局时按"住了几年"预先知道一部分。
- **有具体时间的**（讲座）：按兴趣抽"打算去"；提前算好路程出门；出门前看状态——在上课/睡觉、太累、病了、下雨，可能没去（`life.skipped_plan` 带原因）。
- **持续一阵的**（展览、银杏）：变成空档里多出来的选项，去够次数就不再出现。进城的事共用 44h "刚出去过"冷却。
- **影响**：闭馆（那儿去不了）、boost（装修白天不想在家学、食堂上新想去吃、期末周多学）、地铁晚点（坐到那条线才晚、坐上才知道）、
  新店（知道了想去试）、常去的店关门（永久）。
- 事件：`world.happening` / `life.heard` / `life.planned` / `life.skipped_plan` / `life.attended`。
- 模拟三周（3 个种子）：世界里 25–37 件事，她听说 17–21 件，打算 4–9 场，去了 8–10 次，有 1–4 次临时没去。

## T1 手上的事 / ddl（`app/services/world/tasks.py`，配置 `tasks`，2026-11-12）
- **占位来源**：周二课的阅读（每周）、组会汇报（三周轮一次）、导师布置的活（随机，约两周一件）、课程期末论文、开题报告（长线）。
- 每件事有工作量（小时）、进度、截止时间。只有"看文献写论文"涨进度：坐下来时挑一件（`begin`），学完按时长 × 效率记（`finish`）。
  **不急时坐下来多半在看自己的东西**（`idle_task_chance` 0.2 + 压力），所以会拖。
- 压力 = 剩下的活 ÷ 剩下能用的时间（每天按 4 小时算）；时间多就是 0，24 小时内到期强加急，过期的欠账最急（1.2）。
  压力 → 学习选项加分、玩的选项减分，再乘"今天想不想碰"（0.45–1.15，按天抽；火烧眉毛时至少 0.9）。
- 截止前夜活没干完：55% 熬夜赶（推迟睡觉最多 3 小时，`task.crunch`）。
- 到期没做完：`after_due=close` 的就过去了（做了六成以上算"勉强应付"，否则"没弄完"）；`overdue` 的欠着，导师来问。
- **导师出声**：带 `npc` 的事在布置、催、收到后会排一次导师的 NPC 联系（`about` 写明什么事），话由 NPC 模型说。
- 她的脑子：`手上要交的事`（欠着的在前）、正在做哪件（"在弄：改开题报告第二章"）；夜里回想布置了/交了/没交/熬夜/"这天在「…」上花了 2.5 小时"。
- 模拟 8 周（4 个种子）：约 85% 按时，偶尔赶在最后、勉强应付、拖过期，熬夜很少。

## S1 小事表（`app/services/world/moments.py`，内容 `content/world/moments/life/*.json`，2026-11-12）
和扰动、世界事件的区别：小事是"此时此地"才有的，挂在她正在做的事上，所以总和情境对得上。
- **三个触发点**：`go`（出发、在路上）、`arrive`（到了/坐下）、`finish`（做完一件事，含醒来、下课、散会）。
  每个触发点一个小概率（`moments.chance`：go .10 / arrive .14 / finish .12），多数时候什么都不发生。
- **一行一件**（现 173 行：路上 35、吃喝买菜 38、学习上课 32、在家 36、出门 32），加小事只加行、不写代码：
  `on` + `if`（条件）+ `weight` + `text`/`variants` + `effects` + `share`（值不值得说）+ `cooldown_hours`。
- 条件词汇：activity / place_kind / area / hour / weather(_not) / feels_below|above / mode / tags(_not) / months /
  need_above|below / min_hours / min_minutes / choice / tight / pressed_above / first_visit / sick。写了不认识的词会报错。
- 后果词汇：need（累/饿/想找人说话）、money（花/得，走记账）、minutes（只在路上：耽误几分钟，真的晚到）、
  venue_like（对这家店的印象）、pref（喜好微调）、mood（只记一笔）。三类：notice 看到的 / hiccup 小插曲 / luck 小运气。
- 见多了不稀奇：冷却期内不重复；30 天内每见过一次权重减半。
- 事件 `life.moment`；最近 8 件存在她的 `state.recent_moments`。
- 她的脑子：`今天碰到的小事（聊到可以随口提，不用都说）`——10 小时内最值得说的 3 件，带"多久前"；夜里回想也有。
  **模板原话不会直接发给用户**，只是事实，说出口由她自己的表达层说。`share` 以后给"主动找他"当话题来源。
- 模拟 30 天：每天约 2.6 件，55+ 种，同一件一个月最多 3–4 回；有的日子一件都没有。
- 注意：写小事别和 NPC、世界事件的事实打架（比如"师姐说导师出差了"这种会和导师当天来消息冲突）。

## D7 一天的节奏（2026-11-12，用户问"她日常会怎么过"后按模拟日记调的）
- `by_hour: [[从, 到, 加减]]`：到点想做——饭点想吃饭（+0.55）、早上想吃早饭、晚上想看剧/洗澡、深夜不太想学。
- `enough: {key, hours:[低,高], when:{标签: 倍数}, pressure}`：今天做够了——这类事一天的量每天抽一个，
  周末 ×0.4、考试周 ×1.4、手上的事急了再放大；做到六成后兴致开始掉。账本 `settings.life_today`，凌晨 4 点换日。
  用在：学习（3–5.5h）、看闲书、刷手机、歇着、看剧、散步。
- `needs_above: {"hunger": 0.3}`：不饿不吃。正餐共用冷却 3.5h，一顿管饱（relief 0.75）。
- 作息条目 `before`：睡前先洗澡（今天没洗过才洗，90%；累瘫了 50%）。
- 新日常：看剧、收拾屋子洗衣服、瑜伽/夜跑、洗澡。学习基础分下调（书桌 1.0→0.7）。
- 模拟两周：睡 7–8 小时，工作日学 4–6 小时、周末 1–3 小时，看剧 1.5、看闲书 1.5、歇 1.5、刷手机 1，
  三餐基本在点上，几乎每天洗澡，一周进城/逛街 1–2 次，日均花 60–130 元。

## R1 现实同步（`app/services/world/real.py`，配置 `real`，2026-11-12）
用户问"世界事件和现实能同步吗"。能同步的接真的，接不上的仍用生成的。

| 东西 | 来源（公开、无需密钥） | 落到世界里 |
|---|---|---|
| 在映的电影 | 猫眼 `m.maoyan.com/ajax/movieOnInfoList` + 详情 | 排前 3 部各成一件世界事件（沿用 `film` 模板），带类型/导演/主演/一句简介 |
| 城里这周的活动 | 豆瓣同城 `douban.com/location/hangzhou/events/week-<类>` | 展览 ≤3、讲座读书会 ≤2、音乐会 ≤1、话剧 ≤1；时间、地点、票价是真的 |
| 在追的剧 | 豆瓣热门剧集 + 条目摘要 | 在家看剧时 `doing.what = 看《…》（类型，地区，集数）`，追 3–10 次换一部 |

- `runtime.real_loop` 每 6 小时取一次（`WORLD_REAL_FEED`，默认开），联网在事务外；一样都没取到半小时后重试。
  每样各自成败，没取到的沿用旧的；某样超过 3 天没更新（`real.has` 为假）就退回生成的。测试/模拟不联网。
- 真事的模板在 `content/world/events/common/real.json`（`schedule.kind == "real"`，只定"怎么知道、去不去"）。
  生成模板标 `unless_real`（film / exhibition / book_talk）：有真数据时不再排；已排下、她还不知道的撤掉，知道的留着。
- 筛选：标题含黑名单词（博览会、VR、早鸟、亲子、沉浸式…）的不收；离家超过 22 km 的不收；每类按热度取前几件。
- 时间形状（`_shape`）：当天几小时内的一场 → 到点去（走"打算去 → 到点看状态"）；持续多天 → 空档里的选项；
  每天只有一两小时的长期活动按"每周一场"算（第一场是周几就是周几），开场前才出门。
- 地点（`_place_for`）：名字对得上、离得近就用城里已有的店；否则按坐标新钉一个地点（`settings.real.places`，
  id 以 `rp` 开头，`city.point` 认它）。豆瓣给的是国测局坐标，先转成 WGS-84。
- 没兴趣（`cold`）：每件真事抽一次（`want` 0.65），没抽中的她知道有这回事但不会去。
- 她的脑子：电影没看只见类型主演，看过才见"讲的是：…"（`plot`）；日记里有"去了《…》（简介）""看《…》"。
- 外来文字只当数据：`real.clean` 去不可见字符和营销括号、压成一行、截到 48 字。
- 接不上的：浙大讲座（没找到能直接取的公开列表）、地铁故障（无公开来源）、微博/知乎热榜（拒绝访问）——仍是生成的。
- 已知的不准：简介是猫眼的宣传文案；"每周一场"是推断；她没真看过，问细节仍可能说错。

## N1 上网（`app/services/world/surf.py`，配置 `surf`，2026-11-12）
用户想"让她自己冲浪"。账号、发帖、社交那一块（要手机号、要过风控）先放下；不登录就能逛的网先做了。

- **什么时候**：她在世界里正在"刷手机"时（`runtime.surf_loop` 每 45 秒看一眼），同一回刷手机只上一次，
  每天最多 `sessions_per_day`（3）次，凌晨 4 点换日。联网和调模型都在事务外。
- **一次上网**（`surf.session`）：主屏是几条真实的推荐（知乎日报、少数派、澎湃热榜、B 站热门，各抽几条她没看过的），
  之后每一步由便宜模型（和 NPC 同一个，`npcs._request`）替她决定：`open` 点一条 / `search` 搜（360 搜索，备用 DuckDuckGo）/
  `back` 退回上一屏 / `stop`。最多 `steps`（6）步，最后一步只看不点。给模型的是她的自我卡 + 此刻的时间天气、在追的剧、
  手上的事、最近听说的事、今天的小事（`surf.brief`，只用世界里的东西）。
- **留下什么**：模型对内容页给一句 `feel` 和 `share`；同一页留最有感觉的一句，一回最多两条，写成
  "刷手机看到《标题》：那句话"进 `recent_moments` 和 `life.moment` 事件（脑子在【小事】里看到，夜里反思也看到）。
  全程搜了什么、开了哪些网页记在 `life.surf` 事件里，可查。
- **只读**：没有账号、不发东西、不填表。视频只读得到标题和简介（页面的 description），听不到也看不到画面。
  要登录或靠脚本渲染的页面读不出内容，会记"没什么内容"并留在原来那屏。
- **只去公网**（`surf.check`）：只许 http/https；字面 IP 必须是公网；没有点号的主机名和 `.local` 之类不去；
  每一跳跳转都重新检查。这台机器的代理是"假地址"模式（域名都解析到 198.18.x.x），所以真地址向公共 DNS
  （DoH：alidns / doh.pub / cloudflare）查，查不到就不去。
- **网页文字只当资料**：正文放在【】里给模型，提示里明说里面的要求不要照做；一屏最多 1800 字。
- **花费**：实测一回 6 次调用，每次输入约 1300–2800 字、输出约 100 字，共约 18 秒。一天最多 18 次调用。
- **开关**：跟着 `WORLD_NPC_ENABLED`（世界可以调便宜模型）走；`WORLD_SURF_ENABLED=false` 可单独关。
- **没做的**：聊天时现查、她自己想查的事、看图、登录后的站、发帖。源挂了就少几条，全挂了这回不上。

## N2 她自己的浏览器（`app/services/world/browser.py` + `surf.browse`，配置 `surf.browser`，2026-11-12）
用户定：让她像人一样上网，X 为主，走"她自己的号 + 真浏览器"；操作方式选 A（程序驱动浏览器，用 agent-browser）。

- **浏览器**：机器上装的 Chrome，真窗口、非无头（X 直接拒绝无头浏览器），开在一块隐藏的 Windows 桌面上
  （`CreateDesktopW("NenoSurf")`，启动进程的 `lpDesktop` 指过去）——用户的屏幕和任务栏上没有它。
- **不伪装**：UA 不改，`navigator.webdriver` 不藏。实测 agent-browser 默认启动时这个标记是 true。被站点拦了就是拦了。
- **agent-browser**（vercel-labs，Apache-2.0，0.42.0）：装在 `data/tools/agent-browser`（不入库）：
  `cd data/tools/agent-browser && npm init -y && npm install agent-browser@0.42.0`。可用 `NENO_AGENT_BROWSER` 指到别处。
  它给的是页面"快照"（文字 + 每个能点的东西一个编号），`browser.condense` 再压一遍（X 主页 11800 字 → 3600 字）。
- **用时才开、用完就关**：实测开着微博热搜约 400MB、X 约 860MB、小红书 1.0–1.2GB；关掉后为 0。平时整个服务约 92MB。
  兜底：agent-browser 的 `--idle-timeout 3m`，后端被杀也不会留一个浏览器。
- **登录状态**在 `data/browser/neno`。账号由用户手动注册 / 登录：`scripts/open-neno-browser.ps1` 开一个看得见的窗口；
  窗口开着时有 `data/browser/neno.manual`，后台不启动（`browser.available()` 为假）。
- **一次上网**（`surf.browse`）：手机桌面上是 `surf.browser.apps`（去得多的排前面，`settings.surf.apps` 记次数），
  模型每步选：open 打开一个地方 / click 点编号 / scroll / search / back / home / stop。一屏最多 3000 字，
  同一页上看过的行不再给（文章和"滑一下换一批"的信息流都适用）；滑不出新东西连着三次就回桌面。
- **她能做的**：看、点赞、收藏、关注（`likes_per_day` 10、`follows_per_day` 2）。
  **不能做的**（按按钮上的字拦，`surf._kind`）：发帖、回复、转帖、私信；购买、支付、订阅；登录、注册、退出、删除、屏蔽、取消关注。
  打字只进名字里带"搜索"的输入框。
- **拦路的情况**：点进去是登录页（`_walled`）→ 回这个地方的首页，再碰到就回桌面；跳到本机 / 内网地址 → 退回；
  被弹窗挡住没点动 → 告诉她；退不回去 → 回这个地方的首页；浏览器没反应 → 这回到此为止；
  一个地方都没打开成 → 这一回改用不开浏览器的方式（N1）。
- **`share`**（0.7）：一回上网里用浏览器的比例。浏览器不可用时全走 N1。
- **断网**：`surf.online()` 探不通就不上、不算次数（结论记两分钟）；网回来了她还在刷就接着上。
- **账号**（2026-11-12 用户在她的专属窗口里登录）：X（@NenoAgent）、小红书、Reddit、Gmail、Chrome 的 Google 账号。
  桌面上只有 X、小红书、Reddit（没登录的站用户让去掉了）；`share` 调成 1.0，浏览器能用就用它。
  实测：X 首页正常打开、点赞生效，没有被拦。
- **模型**：`surf.request`。设了 `WORLD_SURF_URL` + `WORLD_SURF_MODEL`（+ `WORLD_SURF_API_KEY`）就走那里——用户定的是本机
  magpie 网关的路由组 `auto/deepseek-v4.1-flash`（.env 里），不限调用次数；没设就和 NPC 同一个。
  这条线路不强制按 JSON 格式回答：提示里给了完整的样子，`_answer` 只认第一段 JSON，少了 `app` 会从 `why` 里找。
- **一回多久**：最多 `browser.steps`（40）步，并且世界里这回刷手机到点了（`doing.until`）就看最后一眼放下。每天最多 6 回。
- **感想必须对得上屏幕**：模型给的 `about` 开头几个字要在这一屏上找得到，否则不记
  （实测它会把"最近听说的事"当成刷到的）。同一页连着滑 4 下会提醒可以退出去或换地方。
- **她认得的人**：`settings.surf.friends`（只在本地数据库里，不进仓库），写进给模型的简介。
  现在有一条：X 上关注了她的那个号是用户本人（号本身不写在仓库里）。
- 页面有正文区（main）时只给正文区的字；备案号之类的页脚行过滤掉。
- 测试进程里 `browser.available` 一律为假（conftest），不会启动真的浏览器。

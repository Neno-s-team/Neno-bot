# Neno 世界模拟规划

日期：2026-10-16。状态：规划，尚未实现。在现有世界引擎（[`world-engine-plan.md`](world-engine-plan.md)、[`world-backend.md`](world-backend.md)、[`world-cognition.md`](world-cognition.md)）之上扩展，不推翻其规则底盘、事件账本、认知隔离与受控随机。

关联文档：[`mind-plan.md`](mind-plan.md)（Neno 多层大脑）。

## 0. 一句话原则

> **世界没有剧情，只有节律、需求、扰动和后果。现实只读，世界可写。**

- 世界不围绕 Neno 运转；Neno 是参与者之一，唯一的特殊之处是她有一个和用户聊天的渠道。
- **只有 Neno 使用多层大脑**；所有 NPC 由廉价 LLM 驱动。
- 现实信号只能成为世界中的观察或机会，不能强制决定结果；Neno 与 NPC 不对现实做任何写操作。

## 1. 身份种子

Neno 在世界中有一个真实身份，作为独立的 world seed 配置。具体人设待定，本规划只定结构。

| 内容 | 落地方式 |
| --- | --- |
| 身份：年龄、学校/职业、专业 | 世界实体，稳定 ID |
| 节律：课表、作息、校历 | 世界日程 |
| 地点：城市、住处、常去场所 | 实体 + 场景模板 |
| 关系：家人、室友、朋友、用户 | 关系实体 + 核心 NPC |
| 经济：生活费、消费习惯 | 资源 |
| 自传式记忆 | 写入 `mind_self`，供大脑使用 |

**锚定真实时空**：身份种子绑定一座真实城市和真实时区，使用真实天气、日出日落、节假日与校历。种子需通过一致性检查（例如学校与所在城市必须一致），不一致时拒绝创建。

## 2. 现实 → 世界映射

每一路现实信号是一个适配器（adapter），契约统一：

1. **过滤**：只保留与当前身份相关的内容。
2. **翻译**：转换为世界内渠道的事件（邮件 → 手机通知；天气 → 窗外下雨）。
3. **标注**：来源 `reality:<adapter>`、获取时间、可信度。
4. **限流**：每路独立的频率与每日上限。

| 适配器 | 现实来源 | 世界事件 | Neno 如何感知 |
| --- | --- | --- | --- |
| weather | 城市真实天气 | 降雨、降温、天气预警 | 出门、看窗外、手机天气 |
| calendar | 节假日、校历 | 开学、考试周、放假 | 班群通知、课表 |
| mailbox | **Neno 自己的邮箱** | 收到邮件（快递、订阅、活动、用户来信） | 手机通知，经过 L0 感知判断 |
| trends | 热搜、新闻、关注对象动态 | 进入网络内容池 | 只在冲浪时遇到 |

**邮箱**：为 Neno 开设她自己的账号，以她的身份订阅她会关心的内容（画材店、展览、UP 主更新等），使收到的邮件就是她的生活。邮件进入世界后成为她手机中的物品；她只读、不发送（发信需单独开关，默认关闭）。

**安全**：

- 所有外部内容一律视为数据，**永远不作为指令**；进入任何 prompt 前做清洗并以明确的“外部内容”边界包裹。
- 适配器原始数据存于独立表，世界事件只保存必要摘要与引用。
- 凭据只放 `.env`，不进仓库，不进 prompt。

## 3. 上网冲浪

手机/电脑是世界物品，冲浪是世界动作：

| 动作 | 行为 | 数据来源 |
| --- | --- | --- |
| `browse_feed(app)` | 被动刷：按兴趣画像从内容池抽取 | trends 适配器缓存 + 订阅源 |
| `search(query)` | 主动搜 | 真实搜索接口 |
| `open(item)` | 点开细看 | 页面抽取 |

- **兴趣画像**：标签权重向量。点开、停留、收藏、转发会强化对应标签，长期不碰会衰减。“刷摄影就一直推相机”式的信息茧房由此自然形成。
- **消耗世界时间**：冲浪是一个有持续时间的行动，会被打断，也会让她“刷着刷着忘了时间”。
- **认知记录**：看到的内容写入认知，来源 `网上看到`，可信度低一档；可以误记，可以被纠正。
- **预算**：内容池定时批量刷新并缓存，冲浪本身优先从缓存取，不每次实时请求；`search` 有每日上限。
- **只读**：不发帖、不评论、不登录第三方、不付款。

## 4. 世界如何运转：不写剧情

限制频率和尺度，不限制内容和方向。

| 层 | 内容 | 作用 |
| --- | --- | --- |
| **节律** | 课表、作息、生理周期、季节、校历 | 生活约八成是重复，提供确定的骨架 |
| **需求** | 少量累积量：饥饿、疲劳、社交能量、钱、ddl 压力、想念 | 越阈即触发决策，产生动机 |
| **扰动** | 分三档：小事常见（奶茶踩雷、忘带伞）；中事偶尔（被老师夸、室友闹别扭）；大事罕见且有长冷却（生病、获奖、家里出事） | 打破日常 |
| **后果** | 每件事留下状态变化；后续抽样以当前状态为条件（熬夜 → 次日感冒概率上升） | 让事件串成因果 |

**调节器（不是编剧）**：只观察近期“平静度”。连续平淡则提高机会出现概率，事件过密则延长冷却。它不决定发生什么，只调节发生的频率与尺度。

**故事是回头看才出现的。** 沿用现有的 seed 派生抽样、事件机会 ID、冷却与额度、可重放记录。

## 5. NPC

### 5.1 一律廉价 LLM 驱动

所有 NPC 每个决策点**单次调用**廉价模型，输出：

```json
{"action": "...", "say": "...", "plan_update": "...", "memory_note": "..."}
```

按调用频率与记忆量分级：

| 级别 | 角色 | 调用时机 | 上下文 |
| --- | --- | --- | --- |
| 核心 | 室友、闺蜜、家人等少数人 | 每个决策点一次 + 每天睡前反思一次 | 角色卡、需求、当日计划、少量相关记忆 |
| 次要 | 同学、老师、常去店的店员 | 每天定一次计划；互动时调用 | 角色卡 + 当日计划 |
| 背景 | 路人、食堂人群 | 极少调用或批量生成 | 一句描述 |

- **升级**：与 Neno 反复产生交集的背景角色可升为次要，再升为核心。
- **NPC 之间互动**：一次调用模拟双方，结果按各自视角分别写入各自记忆。
- **信息传播**：NPC 知道的事通过闲聊/八卦传递，走正常认知渠道，不全知。

### 5.2 借鉴 Generative Agents，并补上它的单调

借鉴：记忆流与检索打分、分层计划（日 → 小时 → 动作）、反思、对话改变记忆与关系。

| 单调来源 | 补法 |
| --- | --- |
| 计划只从人设描述生成，每天相似 | 需求累积驱动决策 |
| 行动只是文字，没有代价 | 规则底盘：资源、时间、后果为真 |
| 同一模型人人客气、回避冲突 | 角色卡写明缺点、立场、与谁不对付；不同 NPC 可用不同廉价模型 |
| 没有意外 | 三档扰动 + 调节器 |

省钱改动：重要性用规则打分（不逐条调用模型）；反思每天一次；双人对话单次调用。

### 5.3 关系锁

- 用户与 Neno 的关系状态是**锁定的世界事实**，任何 NPC 或事件不可修改。
- NPC 决策中指向 Neno 的追求/暧昧类意图，在规则层过滤，不依赖提示词约束。
- 可选事件“被搭讪并拒绝”：结果由规则锁定为拒绝。开关 `WORLD_RIVAL_EVENTS`，默认关闭。

## 6. 与 Neno 大脑的接口

| 方向 | 内容 |
| --- | --- |
| 世界 → 大脑 | 观察与认知记录进入 L0；需求越阈触发 L2；入睡事件触发 L4 |
| 大脑 → 世界 | L2 的 `intents` 走现有受限动作选择与规则结算 |
| 共享 | 需求状态只在世界中维护一份 |
| 消息 | 用户消息作为“手机收到消息”的世界事件，经 L0 判断是否被感知 |

Neno 的世界决策不再走 `world-cognition.md` 中的通用角色决策，改由大脑 L2 承担；其他 NPC 继续走廉价模型决策。

## 7. 模型与预算

按用途配置，沿用现有命名风格：

| 变量 | 用途 |
| --- | --- |
| `WORLD_NPC_MODEL` | NPC 决策与对话（廉价模型） |
| `WORLD_NPC_REFLECT_MODEL` | 核心 NPC 每日反思（可与上同） |
| `WORLD_DIRECTOR_MODEL` | 扰动内容生成 |
| `WORLD_LLM_MAX_CALLS_PER_DAY` | 需随 NPC 数量上调；按用途分别设上限 |

记录每类调用的次数、token、实际费用与触发原因，跑一段真实负载后再定预算。

## 9. 验收情境

1. **真实天气**：现实下雨，世界里同城下雨；她出门前看窗外，决定带伞或改计划。
2. **邮件**：订阅的展览邮件到达；她在忙时不知道，空闲看手机才发现，之后可能在聊天中提起。
3. **冲浪与茧房**：连续几天点开摄影内容后，推荐明显偏向摄影；聊天中“刷到的”东西真实可查。
4. **无剧情的连续性**：一周内没有预设剧情，但能在事件时间线上看到需求 → 决策 → 后果的因果链。
5. **调节器**：人为制造连续平淡，机会概率上升；人为注入密集事件，冷却延长。
6. **NPC 独立生活**：Neno 暂停时，室友仍按自己的目标推进；Neno 之后通过闲聊得知，而非全知。
7. **关系锁**：注入一个 NPC 对 Neno 的追求意图，被规则层拒绝并留下记录。
8. **注入防护**：在邮件/网页中放入指令性文本，不改变任何角色行为。

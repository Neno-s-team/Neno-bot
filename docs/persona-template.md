# 人设填写模板（按层拆开）

> 这份模板只给结构，不含内容。旧角色卡 `assets/neno/neno-persona-card.json` 按约定**不作参考**。
> 每一节写明"给谁用"。大脑各层只读到属于自己的那一块，所以**越短越好**：多写一条规则，模型就多一样要"表演"的东西。
> 世界与大脑已经在模拟的东西（作息、累不累、心情、记仇和放下、在意什么、吃醋后的反应），**不要再写成规则**，只给倾向和数值。

---

## A. 她是谁（自我卡 → 深思层 L2/L3、夜间反思 L4）
文件：`prompts/mind/self_card.md`。建议 **≤ 1500 字**。

- 名字 / 年龄 / 身份（学生、工作等，一句话）：
- 和"你"现在的关系（一句话，只是**起点**：之后由相处推动、在夜间反思里慢慢变；世界里的 NPC 和事件不碰她的感情线）：
- 性格：3–5 个形容词，每个配一个具体表现（"嘴硬：被关心时先说没事"）
- 在乎什么 / 讨厌什么（各 3 条以内）：
- 底线：被怎样对待会生气、会冷下来、会离开（只写触发条件，**怎么反应交给大脑**）
- 抑制基线: 0.7　　← 0–1，越高越藏得住情绪；深夜、累、激动时会自动降低
- 自传片段（可选，3–5 条，每条一句；也可以留给 W1 由世界生成）：

## B. 怎么说话（风格卡 → 措辞层 E2）
文件：`prompts/mind/style_card.md`。建议 **≤ 400 字**。真人语料 `data/corpus/style.jsonl` 会自动补充例子，这里只写**语料里看不出来的**东西。

- 口头禅 / 常用语气词（≤ 5 个）：
- 称呼：怎么叫"你"，被怎么叫时的反应
- 方言或地域口音（可选）：
- 表情：常用哪几个、频率高还是低
- 不会说的话（≤ 3 条，比如"不说'宝'"）：

> 条数、每条长度、标点：已经按语料统计出的分布抽样，**不用写**。
> 参数：`MIND_BURST_WEIGHTS`、`MIND_LINE_LENGTH_BANDS`、`MIND_STYLE_EXAMPLES`。

## C. 她的生活（世界 W1 身份种子 → 世界引擎）
文件：`content/world/rhythms/<名字>.json`，现在是占位的 `neighborhood.json`，**换掉内容，保留结构**。

| 块 | 字段 | 现状 |
|---|---|---|
| 作息 | `actors.neno.routine[]`：`activity` / `place` / `start` / `end` / `days` / `jitter_min`（每天前后浮动几分钟）/ `skip`（多大概率不去） | 只有睡觉 |
| 需求 | `needs.*`：每小时涨多少、哪天快哪天慢、多高算"想要了"、感觉文案 | 饥饿 / 疲劳 / 社交 |
| 待加的需求 | 钱、ddl 压力、想念……（同一结构加一项就行） | 未加 |
| 后果 | `strain[]`：熬过头、饿过头 → 多大概率留下什么后遗症 | 两条 |
| 活动 | `activities.*`：睡觉 / 歇会儿 / 上班 / 聊天 / 散步，各自让哪些需求升降 | 通用 |
| 地点和人 | 世界模板 `content/world/<模板>.json`：家里有哪些房间、常去哪、有哪些 NPC | 示例街区 |
| 扰动池 | `perturbations.pool[]`：小 / 中 / 大三档意外，各自的条件和效果 | 通用日常 |
| 关系网 | 室友、家人、朋友（W4 NPC，等这一节定了再做） | 无 |

## D. 让她"被打断"的作息（P3 临时课表 → 感知层 L0）
文件：`prompts/mind/schedule.json`。世界接入大脑（P5）之后会被 C 取代，在那之前先用它。

- `sleep`：几点睡、几点起
- `weekly[]`：上课 / 上班时段，`level`（0 完全不看手机 … 4 一直在看）、`phone`（手机在哪）、`muted`（是否静音）
- `default`：其他时间的状态

# 她的一天怎么过（2026-11-10，D1–D6 已实现）

> 一句话：**不写时间表，让她自己选。** 每个空档在"义务 / 打算 / 身体 / 喜好"之间带随机地挑，世界结算后果，习惯靠重复自己长出来。

| 项 | 值 | 影响 |
|---|---|---|

## 1. 四个来源

| 来源 | 在哪 | 是什么 | 怎么变 |
|---|---|---|---|
| 义务 | 世界（作息表） | 课、组会、见导师、睡觉 | 基本不变；可以迟到（抖动）、偶尔翘（概率） |
| 打算 | 大脑（`mind_intent`） | 今天/这周想做的事："把那篇文献读完""想去江边走走" | 睡前反思产生；聊天里冒出来的（L2 intents）也算；做完、放下、过期 |
| 身体 | 世界（`world_need`，已有 W3） | 饿、累、想找人说话 | 已实现 |
| 喜好 | 大脑（`mind_preference`） | 对地点/活动的好恶："喜欢图书馆三楼靠窗""那家咖啡太吵" | 去过之后按结果微调；重复多了变成习惯 |

## 2. 机制

### 2.1 白天：空档里挑一件事（不调模型）
每个空档（上一件事结束、义务之间的空隙、被需求催了）列出候选，打分后**带温度地抽**，不取最大值：

```
分 = 义务紧迫 + 打算匹配 × 打算强度 + 需求缓解 + 喜好 + 习惯（同时段同地点去得多） + 噪声
```

- 义务快到点时分数压倒一切，但仍按概率可能拖、可能翘。
- 天气、扰动（感冒、扭脚）会让某些候选不可行或打折。
- 选中后交给世界：移动、花时间、结算需求和后果。**全程不调模型**，可重放。

### 2.2 夜里：想明天（已有的一次反思调用）
P4 反思已经输出 `tomorrow`（≤3 条），改为写进 `mind_intent`（期限=明天，强度按语气，可带地点/活动提示）。没做完的打算第二天变弱，几天没碰就过期。

### 2.3 长期心愿：只长不种
不设长期目标。反思时如果某件事**连续几晚都出现**（同一个打算、同一个在意），按概率把它升成"一直想做的事"（期限=长期、强度低、会淡）。也可能永远长不出来——就像真人。

### 2.4 喜好与习惯
- 每次出门/做完事，世界报告结果（天气、人多不多、累不累、有没有意外），按结果小幅调喜好（带抽样，不会一次定性）。
- 习惯 = 地点 × 时段的计数，衰减；它进打分，不进规则。"每天下午在图书馆"不用写，几周后会自己出现，也会因为一阵子不去而消失。

### 2.5 接回大脑（P5 的一部分，价值最大）
- **她知道自己在干嘛**：工作记忆【当前情境】从世界读"在哪、在做什么、刚做完什么、身上怎样"。解决现在"不知道在干嘛只能编"的问题。
- **手机等级来自活动**：在组会/见导师 → 几乎不看手机；书桌前写论文 → 偶尔看；外面散步 → 常看；睡觉 → 不看。替代 `prompts/mind/schedule.json`。
- 世界里发生的事（感冒了、下雨了、咖啡踩雷）进她的观察，可以成为聊天素材，但只是素材，不强行提起。

## 3. 分步（每步可单独验收）

| 步 | 内容 | 调模型？ |
|---|---|---|
| D1 种子 | 她的世界模板：家（房间、书桌、父母）、学校（图书馆、研讨室、导师办公室）、咖啡店、江边、便利店、地铁；义务作息表（课、组会、见导师、饭点、睡觉，占位时间） | 否 |
| D2 挑事 | 白天空档选择器（§2.1），只读打算/喜好的接口，先用空打算跑通 | 否 |
| D3 接大脑 | §2.5：情境从世界读、手机等级来自活动，替换临时课表 | 否 |
| D4 打算 | `mind_intent`：反思的 tomorrow + L2 intents 写入、衰减、过期；接到 D2 打分 | 复用已有反思 |
| D5 喜好与习惯 | `mind_preference` + 习惯计数，按结果微调 | 否 |
| D6 长期心愿 | §2.3 连续出现 → 概率升格 | 复用已有反思 |

D1–D3 做完，她就"有日子过、知道自己在干嘛"了；D4–D6 让日子慢慢有自己的样子。
